# Хот төлөвлөлтийн систем

Монгол орны дурын газарт полигон зурж, хот төлөвлөлт, суурьшлын тохиромжийг шинжилдэг Next.js апп.
Шалгуур, оноо, ангиллын логик нь `I:\Booroljuut\web\lib\urbanSuit.ts`-ээс зөөгдсөн.

## Ажиллуулах

```
npm install
npm run dev -- -p 3001   # http://localhost:3001 (3000 портыг Бөөрөлжүүт ашиглаж байж болзошгүй)
```

`public/data/` (хил) ба `data/infra/` (зам, шугам) бэлэн байгаа. Шинэчлэх бол:

```
npm run boundaries   # I:\EIC → public/data/*.geojson  (өөр хавтас: EIC_DIR=...)
npm run infra        # Geofabrik-ийн OSM файл → data/infra/<lon>_<lat>.json
npm test
```

## Cloud-д байршуулах

**Vercel (хувийн demo):** Add New → Project → энэ repo → Deploy. Тохиргоо нэмэх шаардлагагүй, сервер Хонконгт (`vercel.json`). Hobby багц зөвхөн арилжааны бус хэрэглээнд; арилжааны бол Pro.

`Dockerfile` нь контейнер дэмждэг бусад cloud дээр ажиллана (порт 8080).

**Render:** New → Blueprint → энэ repo-г холбоно. `render.yaml` тохиргоог уншиж, `main`-д өөрчлөлт орох бүрт дахин байршуулна. HTTPS автомат.

`render.yaml` үнэгүй багцтай: 15 минут хэрэглээгүй бол унтаж, дараагийн нээлтэд ~1 минут хүлээнэ, CPU сул тул үнэлгээ удаан. Төлөвлөгч хөтөч дээр ажилладаг тул сервер нэг шинжилгээнд ~300 МБ санах ой хэрэглэнэ; олон хэрэглэгчтэй болбол 1–2 ГБ-тай төлбөртэй багц руу шилжинэ. Сервер AWS S3, `arcgis.ubhub.mn`, Бөөрөлжүүт FeatureServer рүү гарах интернэт шаардана.

## Нэвтрэлт

`arcgis.ubhub.mn/arcgis` порталын аккаунттай хэрэглэгч бүр нэвтэрч болно (өөр портал: `ARCGIS_PORTAL_URL`).

- Портал CORS зөвшөөрөхгүй тул сервер `generateToken` дууддаг (`lib/server/auth.ts`). Нууц үгийг хадгалахгүй, логт бичихгүй.
- Token нь JavaScript уншихгүй `httpOnly` күүкид 8 цаг хадгалагдана. `/api/prepare` хүсэлт бүрт порталаар шалгана (5 минут кэшлэнэ).
- **HTTPS шаардлагатай:** HTTP дээр нууц үг сүлжээгээр нээлттэй дамжина. `localhost`-оос бусад хаягаар ашиглах бол HTTPS proxy-ийн ард ажиллуулна. HTTPS дээр күүки автоматаар `Secure` болно (proxy нь `X-Forwarded-Proto` дамжуулах ёстой).
- SAML/нэг удаагийн нэвтрэлттэй (SSO) аккаунт `generateToken`-оор нэвтэрч чадахгүй.

## Суурьшил төлөвлөлт

«Төлөвлөлт» таб нь зурсан полигон дээр зам, блок, барилга, ус, бохир, дулаан, цахилгаан, борооны усыг төлөвлөж 2D/3D-ээр харуулна (`lib/plan/`, Бөөрөлжүүтийн `runPlan`). Тооцоо Web Worker-т явагдах тул хуудас гацахгүй; ихэвчлэн 2–6 минут. Полигон ≤500 км².

Байршил сонголт (`lib/plan/runSettlement.ts`, бүх босго ТААМАГЛАЛ):
- Хасна: гадаргын хэлбэрээр 1–3 түвшин, ус, намаг, ой, ±1 км-т өндрийн зөрүү >150 м (уул), гол мөрнөөс 500 м (OSM), ус хураах талбай >2000 га шугамаас 200 м.
- Мөн хасна: ТХГН, нуур, газар тариалан. Нүдээр биш яг хилээр нь (`prep.noBuild`), тул нүднээс жижиг талбар ч үлдэхгүй. Давхарга татагдаагүй бол төлөвлөгөөний тайлбарт бичнэ.
- Хамгийн ойрын сум, аймгийн төв рүү чиглүүлнэ.
- Тасархай хэсгүүдийг нийлүүлэхгүй: хэрэгцээт хэмжээтэй хамгийн ойр нэг хэсгийг, эс бөгөөс хамгийн том хэсгийг авч хүн амыг багтах хэмжээнд багасгана.

Замын дүрслэл нь Бөөрөлжүүтийн B01-ийн `roadContext` / `streetModel` загвар: холбогдсон уулзвар, голын тусгаарлах зурвас, явган гарц, 0.15 м өргөнтэй тасархай эгнээний тэмдэглэгээ. Геометрийг тусдаа Worker-т бэлтгэж 2D/3D-д ижил метрийн хэмжээгээр зурна. Замын огтлол, хашаа/хорооллын орцын мэдээллийг загварт хадгална; хуучин хадгалсан загварын огтлолыг байгаа хучилтаас сэргээнэ.

Эх кодоос зөрсөн: хүн амын таарц ±3% → ±5%, давталт 8 → 5 (хурдны төлөө); дулаан 60 Вт/м², цахилгаан 3 кВт/өрх анхдагч; өндөр нь Copernicus GLO-30; төмөр замаас эхлэх горим, бүс хоорондын холболт, замын хөдөлгөөний 3D загварууд ороогүй.

## Стандарт

«Стандарт» таб нь норм, жишгийг заалтаар нь тухайн төлөвлөгөөний бодит утгатай тулгана (`lib/standards.ts`). Статус нь автомат тулгалт, нийцлийн албан ёсны дүгнэлт биш.

- БНбД 30-01-24: [mcis.gov.mn дээрх файл](https://mcis.gov.mn/storage/uploads/process/202403/file_1710112307903138_162364495749810.pdf) «ТӨСӨЛ» гэсэн тэмдэгтэй, яамны жагсаалтад БНбД 30.01.04 байна. Батлагдсан эсэхийг ШАЛГАХ, 30-01-04-ийн эх бичвэртэй тулгаагүй.
- Бохир, ус, дулаан нь концепт тооцоо тул заалтаар тулгаагүй: «Хэсэгчлэн».
- Тооцоонд ороогүй нормуудын жагсаалтыг `lib/standards.ts`-д хадгална (гал, газар хөдлөлт, нарны тусгал г.м.).
- Төлөвлөгч орон сууцны FAR-ыг 1.2-оор хязгаарладаг (`NORM.farRes`); Х.6.1-ээр 3–6 давхарт 0.8 тул 5 давхрын төлөвлөгөө зөрүүтэй гарч болно.

## Загвар хадгалах

«Төлөвлөлт» табын «Хадгалсан загвар» хэсэг нь төлөвлөгөөг хэрэглэгчийн порталын эрхээр хадгалж, нээнэ (Бөөрөлжүүтийн `lib/portalPlans.ts`-ийн формат).

- Item: төрөл `Code Sample`, tag `hot-tuluwlult-plan`, «Хот төлөвлөлт» хавтаст, файл нь `plan.json` агуулсан zip (`lib/savedPlan.ts`).
- Портал CORS зөвшөөрөхгүй тул хөтөч `/api/plans`-оор дамжина (`lib/server/portalPlans.ts`).
- Хадгална: зурагт, самбарт хэрэгтэй геометр, үзүүлэлт, тохиргоо, талбай. Хадгалахгүй: өндрийн тор, граф, тохиромжийн үнэлгээ (чекээр дахин тооцно).
- Нэр хэвээр, өөрийн item бол «Шинэчлэх»; нэр солисон эсвэл бусдын загвар бол шинэ item үүснэ. Бусдын item-ийг дарж бичихгүй.
- Хуваалцах: бүх байгууллагад (Бөөрөлжүүттэй адил). Тодорхой бүлэгт бол `ARCGIS_SHARE_GROUP`-д бүлгийн id өгнө.
- Дээд хэмжээ 4.4 МБ (Vercel-ийн хүсэлтийн хязгаар). 10,317 хүний төлөвлөгөө 0.52 МБ. Portal-д item үүсгэх эрхгүй (Viewer) аккаунт хадгалж чадахгүй, нээж чадна.

## Ашиглах дараалал

1. Аймаг, сумаа сонгоно. Нарийвчлах бол полигон зурна (сонголтоос давуу).
2. «Тохиромжтой байдлын үнэлгээ» чекийг асаахад үнэлгээ эхэлнэ. Сум 5–12 сек (100–500 м нүд), аймаг 9–29 сек (500–3000 м нүд).
3. «Суурьшил төлөвлөх» товчийг дарахад зөвхөн тохиромжтой хэсэгт төлөвлөнө. Полигон зураагүй бол төвөөс 10 км-ийн хүрээнд.

## Эх кодоос зөрсөн зүйл

- Цахилгаан станцын шалгуур, хориг хасагдсан: зөвхөн Бөөрөлжүүтэд хамаатай.
- `natural_zone` хасагдсан: эх кодод жин нь 0.
- ESA WorldCover шалгуур нэмэгдсэн. Үүнгүйгээр нуур хавтгай тул өндөр оноо авдаг.
- Мэдээлэлгүй шалгуурыг 0.5 оноогоор нөхөхгүй, жингээс хасаж хамралтыг тайлагнана. Эх кодын `evaluate` мэдээлэлгүйг 0.5 гэж тооцдог.
- Анхдагч ангилал нь тогтмол босго: газар хооронд харьцуулах боломжтой. Харьцангуй аргыг тохиргооноос сонгоно.
- D8 урсацын өмнө хотгор дүүргэнэ (`01_surface_suitability.py`-тэй адил).
- UTM бүс автомат; эх код зөвхөн UTM 48N.
- Төлөвлөгч тохиромжтой талбайг эх кодын `surfaceOnly()`-оор ялгана: зөвхөн гадаргын хэлбэр, тогтмол босго. Жалганы хориг 1 м DSM шаарддаг тул хасагдаж, ус, намаг, цасны хориг нэмэгдсэн.

## Хязгаарлалт

- ТААМАГЛАЛ: оноо, жин, босго бүгд концепт шатны санал. WorldCover-ын оноог Бөөрөлжүүтийн газрын ангилалд дүйцүүлсэн. БНбД-ээр ШАЛГАХ.
- ДУТУУ ӨГӨГДӨЛ: инженер-геологи, гүний ус, үерийн түвшин, газар хөдлөлт, газар тариалангаас бусад кадастр.
- ТААМАГЛАЛ: ТХГН-ийг ангилал, бүсчлэлээр ялгалгүй бүгдийг, газар тариалангийн нэгж талбарыг бүгдийг, голоос 500 м-ийг хатуу хориг гэж үзэв. Эх сурвалж TXG20230102 тул 2023 оноос хойшхи өөрчлөлт, орон нутгийн хамгаалалтад авсан газар ороогүй байж болзошгүй. Хуулиар ШАЛГАХ.
- Том нүдтэй үнэлгээнд (аймаг 500–3000 м) хоригийг нүдний төвөөр тогтооно: нүднээс жижиг талбар алдагдаж, том талбар ойролцоогоор гарна. Төлөвлөгч яг хилээр нь хасна.
- Бөөрөлжүүтийн хүрээнээс гадна хөрс, цэвдэг, ургамлын шалгуур байхгүй. Апп үүнийг «Мэдээллийн хамралт»-аар харуулна.
- Эх ангиллын хүснэгтэд ороогүй ангилал (жишээ нь 48-аас 42 хөрсний төрөл) оноогүй үлдэж, шалгуурын хамралтыг бууруулна. Шинэ оноо зохиогоогүй.
- OSM бүрэн бус байж болзошгүй. Шошгогүй гол замыг хучилттай гэж үзнэ (ТААМАГЛАЛ). Зай нь шулуун.
- Урсацын ус хураах талбай тооцооны хүрээгээр (≥5 км зурвас) хязгаарлагдана.
- Нүд 30–2000 м, том полигонд автоматаар томорно. 100 м-ээс том нүдэд налуу, урсацыг 100 м орчмын торонд тооцож нүдний медианаар авна, тул нүдний дотор гарах нарийн гуу жалга хоригт орохгүй. Дээд хязгаар 50,000 км².
- Сервер нь `public/data`, `data/infra`-г файлын системээс уншдаг тул Node сервер (`next start`) дээр ажиллуулна.
